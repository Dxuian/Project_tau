# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Rules

- **Everything runs in Docker.** Never run node, npm, tsc, emcc or tests on the host. Top level: `./dev <cmd>`; library: `cpuminer-opt-js/dev <cmd>` (see `cpuminer-opt-js/CLAUDE.md`).
- **No live mining or real-network pool connections from this machine.** Tests use mocks and a private regtest bitcoind (`docker compose` service `bitcoind`: no peers, `-connect=0`).
- **Consent-first:** nothing mines until a visitor starts it. Don't add stealth features.
- Private repo, no license, not published. Dependencies are exact-pinned and installed with `--ignore-scripts`; any new runtime dependency needs the AUDIT.md treatment.

## Layout

- `btc.js`: the site API: `createWallet`, `walletFromMnemonic`, `mineBTC` (browser/Node); `startPayoutBridge`, `verifyPayout`, `payout`, the `esplora`/`bitcoinCore` chain clients (server). It imports the miner from `cpuminer-opt-js/dist/` (committed build output). Node-only code uses `process.getBuiltinModule` lazily so the file bundles for browsers.
- `btc.browser.js`: generated by `./dev build` (esbuild, `scripts/build-browser.mjs`); `cpuminer-opt-js/dist` stays external. `test/browser.test.js` fails if it is stale, so rebuild and commit it with any `btc.js` change.
- `cpuminer-opt-js/`: the miner library (its own CLAUDE.md). `btc.js` relies on its bridge `intercept` hook (`BRIDGE_FEATURES`); after changing the library, run `cpuminer-opt-js/dev build` and commit `dist/`.

## Payout verification (read before changing it)

- The bridge's auditor (`createAuditor`) is the trust anchor: it rewrites visitors' stratum logins to the owner address, binds each connection to its first authorized payout address, allowlists stratum methods, re-serializes JSON, and records raw share fields (`shares.jsonl`).
- `verifyPayout` rebuilds headers from raw fields (never stored hashes) and pays only for blocks in the best chain with ≥100 confirmations whose coinbase txid equals the rebuilt one and pays the owner; once per block via `payouts.jsonl` (pending → sent, "void" releases an attempt) plus a lock file.
- Header rebuild conventions: prevhash is stratum's word-swapped form (`swap32`), version/nbits/ntime/nonce are reversed big-endian hex, merkle branches are used as given; tested against Bitcoin block 1 and against real regtest blocks accepted by bitcoind.
- Amounts are bigint satoshis. Coin selection is our own largest-first (btc-signer's `selectUTXO` is unaudited); fee from an upper-bound vsize formula, checked against the signed tx.
